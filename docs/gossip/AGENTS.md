# AGENTS.md: gossip

The root `AGENTS.md` applies. This file covers the gossip part of `addons/Spoken_Quests`.
`docs/gossip/README.md` is the reference. The pipeline that builds gossip lines and packs is
`docs/quests/CLAUDE.md`, because Quests and Gossip share one corpus, one set of packs and one site
section.

## Rules that bite

- Gossip is a part of Spoken inside the Quests addon, not a module of its own. A new kind of NPC
  window is a new source in that addon; a new kind of game event is a new folder. Notes players
  see go under `## Unreleased` in `docs/spoken/CHANGELOG.md`.
- The saved names `GossipFrequency`, `StopAudioOnDisengage`, `OGThrall`, `GreetingFirst` and
  `hasSeenGossipForNPC`, and the variable `SpokenQuestsSettings`, are what players already have.
  Renaming one drops their choice without an error.
- The core's global `VoiceOver` keeps its name. Every sound pack ever built calls
  `VoiceOver.DataModules:Register(...)`, and packs on players' disks cannot follow a rename.
- `Gossip/<lang>.lua` and `Gossip/Aliases.lua` are generated by `make quests-export-gossip-text`.
  Never edit them by hand, and regenerate them after `import-locale`, a cache upload or a relink.
- Which part owns a window comes from `Addon:PartOfPage(event)`: `GOSSIP_SHOW` and
  `QUEST_GREETING` are Gossip's, every other event Quests'. Each button, queue entry and
  contribution asks it, so a window of one part never speaks for the other. A new window goes in
  that function.
- Read Automatically is one switch for every NPC window and lives on the Quests page. The Gossip
  page's rows that only decide what it reads are greyed while it is off.
- The Thrall easter egg is keyed on the line's file name (`EasterEggs.lua`), and `RunSelfTest`
  uses the same name, so a renamed file breaks both.
- `Player:HoldsGossip` lists the packs that hold no gossip (`QUEST_ONLY`: Alliance, Horde,
  Shared). A new pack that holds quests alone must be added there, or the settings page and
  Show Diagnostics count it as a gossip pack.
- Gossip lines are queued with priority `low` (`Player:Prepare`): a gossip line queued behind a
  quest line yields to it and the log says `queue-outranked`.
- Ids and file names in the root `AGENTS.md` (`g:{md5}`, `g:b{id}-{voice}`, `g:{lang}-{md5}`) are
  frozen. `Aliases.lua` links lines of one moment and never renames one.

## Tests

Run each with `luajit tests/lua/<name>`; `make test-player` runs them all.

- `gossip_part_test.lua`: the two sources, which part a window belongs to, and one part off
  leaving the other speaking.
- `gossip_frequency_test.lua`: Read Greetings values, Never and the Listen button.
- `gossip_variant_test.lua`: one NPC with several texts, a text the packs lack, and the player's
  tokens filled into a line before it is compared.
