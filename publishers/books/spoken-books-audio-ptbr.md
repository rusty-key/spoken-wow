Narrated books, letters and notes for **[Spoken Player](https://www.curseforge.com/wow/addons/spoken-player)**'s Books module, in Brazilian Portuguese. This addon is data only — it does nothing on its own.

One clip per page, read from the Portuguese text players' clients have sent in — Classic's world database has none of its own, so it covers only the pages contributed so far. It installs beside the English pack, **[Spoken Books Audio](https://www.curseforge.com/wow/addons/spoken-books-audio)**, rather than replacing it, so a player who switches languages keeps the narration for both.

## Installing

Install **Spoken Player** first; this pack is inert without it. Extract into `Interface/AddOns` and leave the folder name as shipped (`SpokenBooksAudio_ptBR`).

Spoken Books reads in your client's language, so this pack plays on a Portuguese client. A page it does not hold is read in English instead.

## Compatibility

Built for **Classic Era 1.15.9**, with Spoken Player 3.0.0 or later.
