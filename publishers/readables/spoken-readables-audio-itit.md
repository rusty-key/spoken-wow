Narrated books, letters and notes for **[Spoken](https://www.curseforge.com/wow/addons/spoken)**'s Readables module, in Italian. This addon is data only — it does nothing on its own.

One clip per page. It installs beside the English pack, **[Spoken Audio: Readables](https://www.curseforge.com/wow/addons/spoken-audio-readables)**, rather than replacing it, so a player who switches languages keeps the narration for both.

## Installing

Install **Spoken** first; this pack is inert without it. Extract into `Interface/AddOns` and leave the folder name as shipped (`SpokenReadablesAudio_itIT`).

Spoken Readables plays it when Spoken's **Voice Language** is Italian. There is no Italian game client, so pick Italian on Spoken's settings page. A page this pack has no narration for is read in the language set under **If a Voice Is Missing**, English unless you change it.

## Compatibility

For **WoW Forever**, Classic Era and Anniversary, with Spoken 3.0.0 or later.
