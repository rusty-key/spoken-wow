**This addon is retired. Spoken Books is now part of [Spoken](https://www.curseforge.com/wow/addons/spoken).**

Spoken carries Spoken Books (books, letters, notes and plaques read aloud) together with the other Spoken modules, in one download, where the module is now called Readables. This project gets no further updates.

## What to do

1. **Install [Spoken](https://www.curseforge.com/wow/addons/spoken).**
2. **Uninstall this addon**, and delete the `SpokenBooks` folder from `Interface\AddOns` if it is still there. Its last update left a folder that never loads, listed greyed out as "Spoken Books (now in Spoken)".
3. **Keep your voice packs.** [Spoken Audio: Readables](https://www.curseforge.com/wow/addons/spoken-audio-readables) and the language packs work with Spoken unchanged.

If a full old copy is still installed, Spoken switches it off at login and offers **Reload Now**, so no line plays twice.
