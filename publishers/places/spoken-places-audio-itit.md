Narrated zone lore for **[Spoken](https://www.curseforge.com/wow/addons/spoken)**'s Places module, in Italian. This addon is data only — it does nothing on its own.

Spoken Places plays it when Spoken's **Voice Language** is Italian. It installs beside the English pack, **[Spoken Audio: Places](https://www.curseforge.com/wow/addons/spoken-audio-places)**, rather than replacing it, so a player who switches languages keeps the narration for both.

## Installing

Install **Spoken** first; this pack is inert without it. Extract into `Interface/AddOns` and leave the folder name as shipped (`SpokenPlacesAudio_itIT`) — Spoken finds packs by folder name.

There is no Italian game client, so pick Italian under **Voice Language** on Spoken's settings page. A place this pack has no narration for is read in the language set under **If a Voice Is Missing**, English unless you change it.

## Compatibility

For **WoW Forever**, Classic Era and Anniversary, with Spoken 3.0.0 or later.
